# P5-1: Structured Data Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `obot.data`: the storage layer that lets bots keep JSON records in typed collections with three scopes (personal, shared, group), enforced rules, plan limits and isolation, ready for the bot tools (P5-2) and the panel (P5-6).

**Architecture:** Three tables in the existing Postgres (`collections`, `records`, `record_keys`). Pure schema logic (field types, normalization, rules, schema evolution) lives in `obot/data/schema.py` with no DB access. Every DB read or write takes a `DataSpace` (who is asking, on which bot, in which chat) and goes through `obot/data/repository.py` (collections and record writes) or `obot/data/query.py` (find, availability, summarize). Uniqueness is enforced by a real primary key on `record_keys`, so concurrent writers cannot double-book.

**Tech Stack:** Python 3.13, SQLAlchemy 2 async + asyncpg, Postgres 17 (JSONB), Alembic, Pydantic 2, pytest-asyncio.

**Spec:** `docs/SPEC.md` section ۸٫۸ (phase 5). This plan covers row P5-1 only. Tools, factory, events, panel and group UX are later plans.

## Global Constraints

- Plan limits come from `plans.yaml`, never hard-coded (AGENTS.md).
- Records are only ever queried through `obot.data` with a `DataSpace`; no other module touches `Record` or `RecordKey` directly (same rule as chat memory).
- Schema changes on a collection that has records are additive only: no field removal (hide instead), no type change, no new required field, choice options only added, min/max only widened, no new unique rule.
- Stored formats: number/money as decimal strings (`"250000"`, `"2.5"`), date `YYYY-MM-DD`, time `HH:MM`, datetime UTC `YYYY-MM-DDTHH:MM:SSZ`, boolean as JSON bool. Persian/Arabic digits are converted to ASCII.
- Time zones: personal collections use the caller's timezone; shared and group collections use the bot owner's.
- In a group chat (`DataSpace.tg_chat_id` set) only group collections are visible; in private chats group collections are hidden. This keeps personal and shared data out of groups (SPEC 3.4).
- In shared collections a non-owner reads only their own records; "availability" returns only fields marked `public` and may only filter on public fields.
- Soft-deleted records are purged after `deleted_record_retention_days` (default 30).
- Commit messages: one plain English sentence in the imperative, like the existing history (e.g. "Let bots keep structured data in collections"), ending with the `Co-Authored-By` trailer.
- Dev infra must be up for tests: `docker compose up -d` from the repo root. Run tests from `backend/`.

```python
class CollectionScope(enum.StrEnum):
    # Each person has their own records (an expense book).
    PERSONAL = "personal"
    # Everyone writes, each reads their own; the bot's owner reads all (bookings).
    SHARED = "shared"
    # One space per group chat (a family shopping list).
    GROUP = "group"


class Collection(Base):
    """A bot's typed container of JSON records (SPEC 8.8). Always accessed through obot.data."""

    __tablename__ = "collections"
    __table_args__ = (
        UniqueConstraint(
            "bot_id", "key", "created_by_user_id", postgresql_nulls_not_distinct=True
        ),
    )

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True)
    bot_id: Mapped[int] = mapped_column(ForeignKey("bots.id", ondelete="CASCADE"))
    key: Mapped[str] = mapped_column(String(40))
    title: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict)
    scope: Mapped[CollectionScope] = mapped_column(
        Enum(
            CollectionScope,
            native_enum=False,
            length=16,
            values_callable=lambda e: [m.value for m in e],
        )
    )
    # None: part of the bot's template. Set: a personal collection that person made in chat.
    created_by_user_id: Mapped[int | None] = mapped_column(
        ForeignKey("users.id", ondelete="CASCADE")
    )
    # {"fields": [...]}; see obot.data.schema.CollectionSchema
    schema: Mapped[dict[str, Any]] = mapped_column(JSONB)
    rules: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, server_default="{}")
    # Notifications and reminders (P5-5).
    events: Mapped[dict[str, Any]] = mapped_column(JSONB, default=dict, server_default="{}")
    schema_version: Mapped[int] = mapped_column(default=1, server_default="1")
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(server_default=func.now(), onupdate=func.now())


class Record(Base):
    """One JSON row of a collection. Always accessed through obot.data with a DataSpace."""

    __tablename__ = "records"
    __table_args__ = (
        Index("ix_records_collection_author", "collection_id", "author_user_id"),
        Index("ix_records_collection_chat", "collection_id", "tg_chat_id"),
        Index("ix_records_data", "data", postgresql_using="gin"),
    )

    id: Mapped[int] = mapped_column(BigInteger, primary_key=True)
    collection_id: Mapped[int] = mapped_column(ForeignKey("collections.id", ondelete="CASCADE"))
    bot_id: Mapped[int] = mapped_column(ForeignKey("bots.id", ondelete="CASCADE"), index=True)
    author_user_id: Mapped[int] = mapped_column(ForeignKey("users.id", ondelete="CASCADE"))
    # The group chat of a group-scope record; None otherwise.
    tg_chat_id: Mapped[int | None] = mapped_column(BigInteger)
    data: Mapped[dict[str, Any]] = mapped_column(JSONB)
    schema_version: Mapped[int]
    # Bumped on every change; the panel sends it back to detect concurrent edits.
    version: Mapped[int] = mapped_column(default=1, server_default="1")
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(server_default=func.now(), onupdate=func.now())
    # Soft delete; purged after Settings.deleted_record_retention_days.
    deleted_at: Mapped[datetime | None]


class RecordKey(Base):
    """A record's values under one unique rule. The primary key is what makes the rule hold,
    even for concurrent writers (SPEC 8.8)."""

    __tablename__ = "record_keys"

    collection_id: Mapped[int] = mapped_column(
        ForeignKey("collections.id", ondelete="CASCADE"), primary_key=True
    )
    # The rule's field keys joined by commas, e.g. "date,time".
    rule: Mapped[str] = mapped_column(String(400), primary_key=True)
    # Where the rule applies: "u:<user id>" (personal), "all" (shared), "c:<chat id>" (group).
    scope_key: Mapped[str] = mapped_column(String(40), primary_key=True)
    value_hash: Mapped[str] = mapped_column(String(64), primary_key=True)
    record_id: Mapped[int] = mapped_column(
        ForeignKey("records.id", ondelete="CASCADE"), index=True
    )
```

```python
def test_normalizes_persian_digits_and_types() -> None:
    record = validate_record(
        expenses(),
        {"amount": "۲۵۰٬۰۰۰", "category": "food", "at": "2026-10-09T13:30", "paid": "بله"},
        TEHRAN,
    )
    assert record == {
        "amount": "250000",
        "category": "food",
        # 13:30 in Tehran (UTC+3:30) is 10:00 UTC
        "at": "2026-10-09T10:00:00Z",
        "paid": True,
    }


def test_reports_every_problem() -> None:
    with pytest.raises(RecordInvalid) as caught:
        validate_record(expenses(), {"amount": "-5", "category": "cars", "color": "red"}, TEHRAN)
    fields = sorted(e.field for e in caught.value.errors)
    assert fields == ["amount", "category", "color"]


def test_required_fields_on_create_and_partial_update() -> None:
    with pytest.raises(RecordInvalid) as caught:
        validate_record(appointments(), {"name": "Ali"}, TEHRAN)
    assert sorted(e.field for e in caught.value.errors) == ["date", "time"]

    current = validate_record(
        appointments(), {"name": "Ali", "date": "2026-10-10", "time": "17:00"}, TEHRAN
    )
    updated = validate_record(appointments(), {"time": "18:00"}, TEHRAN, current=current)
    assert updated == {"name": "Ali", "date": "2026-10-10", "time": "18:00"}
    with pytest.raises(RecordInvalid):
        validate_record(appointments(), {"name": None}, TEHRAN, current=current)


def test_hidden_fields_are_not_writable() -> None:
    schema = expenses()
    schema.fields[1].hidden = True
    with pytest.raises(RecordInvalid):
        validate_record(schema, {"amount": 1, "category": "food"}, TEHRAN)


def test_allowed_hours() -> None:
    schema = appointments()
    # 2026-10-10 is a Saturday
    check_allowed_hours(schema, {"date": "2026-10-10", "time": "17:00"}, TEHRAN)
    with pytest.raises(OutsideAllowedHours):
        check_allowed_hours(schema, {"date": "2026-10-10", "time": "20:00"}, TEHRAN)
    # 2026-10-16 is a Friday
    with pytest.raises(OutsideAllowedHours):
        check_allowed_hours(schema, {"date": "2026-10-16", "time": "17:00"}, TEHRAN)


def test_unique_keys_skip_missing_values() -> None:
    schema = appointments()
    keys = unique_keys(schema, {"date": "2026-10-10", "time": "17:00"})
    assert [rule for rule, _ in keys] == ["date,time"]
    assert keys == unique_keys(schema, {"date": "2026-10-10", "time": "17:00", "name": "X"})
    assert unique_keys(schema, {"date": "2026-10-10"}) == []

def test_evolution_is_additive_once_records_exist() -> None:
    old = expenses()

    def changed(edit) -> CollectionSchema:
        d = old.model_dump(mode="json")
        edit(d)
        return CollectionSchema.model_validate(d)

    # Without records anything goes.
    replacement = CollectionSchema.model_validate(
        {"fields": [{"key": "x", "label": {"en": "X"}, "type": "text", "required": True}]}
    )
    check_evolution(old, replacement, has_records=False)

    def grow(d) -> None:
        d["fields"].append({"key": "note", "label": {"en": "Note"}, "type": "text"})
        d["fields"][1]["options"].append("travel")
        d["fields"][1]["hidden"] = True
        d["fields"][0]["min"] = None  # widened

    check_evolution(old, changed(grow), has_records=True)

    for edit in (
        lambda d: d["fields"].pop(1),
        lambda d: d["fields"][0].update(type="number"),
        lambda d: d["fields"][2].update(required=True),
        lambda d: d["fields"][1].update(options=["food"]),
        lambda d: d["fields"][0].update(min="10"),
        lambda d: d["fields"].append(
            {"key": "n", "label": {"en": "N"}, "type": "text", "required": True}
        ),
        lambda d: d["rules"].update(unique=[["category"]]),
    ):
        with pytest.raises(SchemaChangeRejected):
            check_evolution(old, changed(edit), has_records=True)
```

```python
"""Errors of the data layer. Each has a stable `code` the bot tools and the API turn into words."""

from dataclasses import dataclass
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from obot.data.schema import AllowedHours


class DataError(Exception):
    code = "data_error"


class CollectionNotFound(DataError):
    code = "collection_not_found"

    def __init__(self, key: str) -> None:
        super().__init__(f"no collection named {key!r}")
        self.key = key


class RecordNotFound(DataError):
    code = "record_not_found"

    def __init__(self, record_id: int) -> None:
        super().__init__(f"no record {record_id}")
        self.record_id = record_id


class NotAllowed(DataError):
    code = "not_allowed"


class InvalidSchema(DataError):
    code = "invalid_schema"


class SchemaChangeRejected(DataError):
    code = "schema_change_rejected"


class InvalidQuery(DataError):
    code = "invalid_query"


class StaleRecord(DataError):
    code = "stale"

    def __init__(self) -> None:
        super().__init__("the record changed since it was read")


class LimitReached(DataError):
    code = "limit_reached"

    def __init__(self, limit: str) -> None:
        super().__init__(f"plan limit reached: {limit}")
        self.limit = limit  # "collections" | "records" | "record_bytes"


class DuplicateRecord(DataError):
    code = "duplicate"

    def __init__(self, fields: list[str]) -> None:
        super().__init__(f"a record with the same {', '.join(fields)} exists")
        self.fields = fields


class OutsideAllowedHours(DataError):
    code = "outside_allowed_hours"

    def __init__(self, allowed: "AllowedHours") -> None:
        super().__init__("outside the allowed hours")
        self.allowed = allowed


@dataclass(frozen=True)
class FieldError:
    field: str
    reason: str


class RecordInvalid(DataError):
    code = "invalid"

    def __init__(self, errors: list[FieldError]) -> None:
        super().__init__("; ".join(f"{e.field}: {e.reason}" for e in errors))
        self.errors = errors
```

```python
"""Collection schemas: fields, rules, and turning loose input into stored values (SPEC 8.8).

Pure functions, no database. Stored formats: numbers and money as decimal strings, dates
YYYY-MM-DD, times HH:MM, datetimes in UTC as YYYY-MM-DDTHH:MM:SSZ, booleans as JSON bools.
ISO strings of one type compare correctly as text, which obot.data.query relies on.
"""

import enum
import hashlib
import json
import re
from datetime import UTC, date, datetime, time
from decimal import Decimal, InvalidOperation
from typing import Any
from zoneinfo import ZoneInfo

from pydantic import BaseModel, Field, field_validator, model_validator

from obot.data.errors import (
    FieldError,
    OutsideAllowedHours,

KEY_PATTERN = r"^[a-z][a-z0-9_]{0,39}$"
MAX_FIELDS = 30
MAX_TEXT = 2000

_DIGITS = str.maketrans("۰۱۲۳۴۵۶۷۸۹٠١٢٣٤٥٦٧٨٩", "01234567890123456789")
_TRUE = {"true", "yes", "y", "1", "بله", "آره", "اره", "هست"}
_FALSE = {"false", "no", "n", "0", "خیر", "نه", "نیست"}


class FieldType(enum.StrEnum):
    TEXT = "text"
    NUMBER = "number"
    MONEY = "money"
    DATE = "date"
    TIME = "time"
    DATETIME = "datetime"
    CHOICE = "choice"
    BOOLEAN = "boolean"
    PHONE = "phone"


NUMERIC_TYPES = frozenset({FieldType.NUMBER, FieldType.MONEY})


class FieldDef(BaseModel):
    key: str = Field(pattern=KEY_PATTERN)
    label: dict[str, str]  # by language, e.g. {"fa": "مبلغ", "en": "Amount"}
    type: FieldType
    required: bool = False
    options: list[str] = []  # choice fields only
    min: Decimal | None = None  # number and money only
    max: Decimal | None = None
    currency: str | None = None  # money only, e.g. "IRT", "USD"
    # Shown to everyone in availability answers of a shared collection (e.g. date and time).
    public: bool = False
    # Kept in stored records but no longer shown or written; fields are never removed.
    hidden: bool = False

    @model_validator(mode="after")
    def _consistent(self) -> "FieldDef":
        if (self.type == FieldType.CHOICE) != bool(self.options):
            raise ValueError(f"{self.key}: choice fields, and only they, have options")
        if (self.min is not None or self.max is not None) and self.type not in NUMERIC_TYPES:
            raise ValueError(f"{self.key}: only number and money fields have min/max")
        return self


class Window(BaseModel):
    weekdays: list[int] = Field(min_length=1)  # 0 = Monday ... 6 = Sunday
    start: time
    end: time  # exclusive

    @model_validator(mode="after")
    def _consistent(self) -> "Window":
        if any(d not in range(7) for d in self.weekdays):
            raise ValueError("weekdays are 0 (Monday) to 6 (Sunday)")
        if self.start >= self.end:
            raise ValueError("a window must start before it ends")
        return self


class AllowedHours(BaseModel):
    # A date field plus a time field, or a single datetime field (time_field None).
    date_field: str
    time_field: str | None = None
    windows: list[Window] = Field(min_length=1)


class Rules(BaseModel):
    unique: list[list[str]] = []
    allowed_hours: AllowedHours | None = None

    @field_validator("unique")
    @classmethod
    def _non_empty(cls, groups: list[list[str]]) -> list[list[str]]:
        if any(not g for g in groups):
            raise ValueError("a unique rule needs at least one field")
        return groups


class CollectionSchema(BaseModel):
    fields: list[FieldDef] = Field(min_length=1, max_length=MAX_FIELDS)
    rules: Rules = Rules()

    @model_validator(mode="after")
    def _consistent(self) -> "CollectionSchema":
        by_key = self.field_map()
        if len(by_key) != len(self.fields):
            raise ValueError("field keys must be unique")
        if any(k not in by_key for group in self.rules.unique for k in group):
            raise ValueError("a unique rule names an unknown field")
        if (allowed := self.rules.allowed_hours) is not None:
            day = by_key.get(allowed.date_field)
            if allowed.time_field is None:
                ok = day is not None and day.type == FieldType.DATETIME
            else:
                at = by_key.get(allowed.time_field)
                ok = (
                    day is not None
                    and day.type == FieldType.DATE
                    and at is not None
                    and at.type == FieldType.TIME
                )
            if not ok:
                raise ValueError("allowed_hours needs a datetime field, or a date and a time field")
        return self

    def field_map(self) -> dict[str, FieldDef]:
        return {f.key: f for f in self.fields}

    def field(self, key: str) -> FieldDef | None:
        return self.field_map().get(key)


def normalize_value(f: FieldDef, value: Any, tz: ZoneInfo, *, check_limits: bool = True) -> Any:
    """The stored form of `value` for `f`. ValueError with a short reason if it does not fit.

    `check_limits` False skips min/max, for values used in filters rather than stored.
    """
    if isinstance(value, str):
        value = value.strip().translate(_DIGITS)
    match f.type:
        case FieldType.TEXT:
            text = str(value)
            if len(text) > MAX_TEXT:
                raise ValueError(f"longer than {MAX_TEXT} characters")
            return text
        case FieldType.NUMBER | FieldType.MONEY:
            if isinstance(value, bool):
                raise ValueError("not a number")
            try:
                number = Decimal(str(value).replace(",", "").replace("٬", ""))
            except InvalidOperation:
                raise ValueError("not a number") from None
            if not number.is_finite():
                raise ValueError("not a number")
            if check_limits and f.min is not None and number < f.min:
                raise ValueError(f"must be at least {f.min}")
            if check_limits and f.max is not None and number > f.max:
                raise ValueError(f"must be at most {f.max}")
            return format(number.normalize(), "f")
        case FieldType.DATE:
            try:
                return date.fromisoformat(str(value)).isoformat()
            except ValueError:
                raise ValueError("not a date (YYYY-MM-DD)") from None
        case FieldType.TIME:
            try:
                return time.fromisoformat(str(value)).strftime("%H:%M")
            except ValueError:
                raise ValueError("not a time (HH:MM)") from None
        case FieldType.DATETIME:
            try:
                moment = value if isinstance(value, datetime) else datetime.fromisoformat(str(value))
            except ValueError:
                raise ValueError("not a date and time (YYYY-MM-DDTHH:MM)") from None
            if moment.tzinfo is None:
                moment = moment.replace(tzinfo=tz)
            return moment.astimezone(UTC).strftime("%Y-%m-%dT%H:%M:%SZ")
        case FieldType.CHOICE:
            choice = str(value)
            if choice not in f.options:
                raise ValueError(f"must be one of: {', '.join(f.options)}")
            return choice
        case FieldType.BOOLEAN:
            if isinstance(value, bool):
                return value
            word = str(value).lower()
            if word in _TRUE:
                return True
            if word in _FALSE:
                return False
            raise ValueError("not yes or no")
        case FieldType.PHONE:
            phone = re.sub(r"[\s\-()]", "", str(value))
            if not re.fullmatch(r"\+?\d{7,15}", phone):
                raise ValueError("not a phone number")
            return phone


def validate_record(
    schema: CollectionSchema,
    data: dict[str, Any],
    tz: ZoneInfo,
    *,
    current: dict[str, Any] | None = None,
) -> dict[str, Any]:
    """Merge `data` into `current` (None for a new record) and return the record to store.

    None or "" clears an optional field. Raises RecordInvalid listing every problem.
    """
    fields = schema.field_map()
    errors: list[FieldError] = []
    result = dict(current or {})
    for key, value in data.items():
        f = fields.get(key)
        if f is None or f.hidden:
            errors.append(FieldError(key, "unknown field"))
            continue
        if value is None or value == "":
            result.pop(key, None)
            continue
        try:
            result[key] = normalize_value(f, value, tz)
        except (ValueError, TypeError) as e:
            errors.append(FieldError(key, str(e) or "invalid value"))
    # A field that failed to normalize already has its error.
    failed = {e.field for e in errors}
    for f in schema.fields:
        if f.required and not f.hidden and f.key not in result and f.key not in failed:
            errors.append(FieldError(f.key, "required"))
    if errors:
        raise RecordInvalid(errors)
    return result


def check_allowed_hours(schema: CollectionSchema, record: dict[str, Any], tz: ZoneInfo) -> None:
    """Raise OutsideAllowedHours unless the record's day and time fall in a window.

    A date + time pair is local wall-clock time; a datetime field is converted to `tz`.
    """
    allowed = schema.rules.allowed_hours
    if allowed is None or allowed.date_field not in record:
        return
    if allowed.time_field is None:
        local = datetime.fromisoformat(record[allowed.date_field]).astimezone(tz)
        weekday, at = local.weekday(), local.time()
    else:
        if allowed.time_field not in record:
            return
        weekday = date.fromisoformat(record[allowed.date_field]).weekday()
        at = time.fromisoformat(record[allowed.time_field])
    if not any(weekday in w.weekdays and w.start <= at < w.end for w in allowed.windows):
        raise OutsideAllowedHours(allowed)


def unique_keys(schema: CollectionSchema, record: dict[str, Any]) -> list[tuple[str, str]]:
    """(rule, value hash) for each unique rule; rules with a missing value are skipped,
    like NULLs in a SQL unique index."""
    keys = []
    for group in schema.rules.unique:
        values = [record.get(k) for k in group]
        if any(v is None for v in values):
            continue
        digest = hashlib.sha256(json.dumps(values, ensure_ascii=False).encode()).hexdigest()
        keys.append((",".join(group), digest))
    return keys


def check_evolution(old: CollectionSchema, new: CollectionSchema, *, has_records: bool) -> None:
    """Raise SchemaChangeRejected unless every record valid under `old` stays valid under `new`."""
    if not has_records:
        return
    new_fields = new.field_map()
    for f in old.fields:
        n = new_fields.get(f.key)
        if n is None:
            raise SchemaChangeRejected(f"{f.key}: fields cannot be removed; hide it instead")
        if n.type != f.type:
            raise SchemaChangeRejected(f"{f.key}: the type of a field cannot change")
        if n.required and not f.required:
            raise SchemaChangeRejected(f"{f.key}: an existing field cannot become required")
        if set(f.options) - set(n.options):
            raise SchemaChangeRejected(f"{f.key}: choice options can only be added")
        if n.min is not None and (f.min is None or n.min > f.min):
            raise SchemaChangeRejected(f"{f.key}: limits can only be widened")
        if n.max is not None and (f.max is None or n.max < f.max):
            raise SchemaChangeRejected(f"{f.key}: limits can only be widened")
    old_keys = old.field_map()
    for n in new.fields:
        if n.key not in old_keys and n.required:
            raise SchemaChangeRejected(f"{n.key}: new fields must be optional")
    old_unique = {tuple(g) for g in old.rules.unique}
    if any(tuple(g) not in old_unique for g in new.rules.unique):
        raise SchemaChangeRejected("unique rules cannot be added once a collection has records")
```

```python
"""Who reads or writes a bot's data, and which records that lets them see (SPEC 8.8).

Every query on records takes a DataSpace; the filters here are the only place the
access rules live. In a group chat only group collections are visible, so personal and
shared data never reach a group.
"""

from dataclasses import dataclass
from zoneinfo import ZoneInfo

from sqlalchemy import ColumnElement
from sqlalchemy.ext.asyncio import AsyncSession

from obot.db.models import Bot, Collection, CollectionScope, Record, User


@dataclass(frozen=True)
class DataSpace:
    bot_id: int
    owner_id: int
    user_id: int  # the caller
    timezone: str
    owner_timezone: str
    plan: str
    owner_plan: str
    tg_chat_id: int | None = None  # set in a group chat
    is_group_admin: bool = False

    @property
    def is_owner(self) -> bool:
        return self.user_id == self.owner_id


async def space_for(
    session: AsyncSession,
    bot: Bot,
    user: User,
    *,
    tg_chat_id: int | None = None,
    is_group_admin: bool = False,
) -> DataSpace:
    owner = await session.get(User, bot.owner_id)
    return DataSpace(
        bot_id=bot.id,
        owner_id=owner.id,
        user_id=user.id,
        timezone=user.timezone,
        owner_timezone=owner.timezone,
        plan=user.plan,
        owner_plan=owner.plan,
        tg_chat_id=tg_chat_id,
        is_group_admin=is_group_admin,
    )


def visible(space: DataSpace, c: Collection) -> bool:
    if c.bot_id != space.bot_id:
        return False
    if c.created_by_user_id is not None and c.created_by_user_id != space.user_id:
        return False
    return (c.scope == CollectionScope.GROUP) == (space.tg_chat_id is not None)


def row_filter(space: DataSpace, c: Collection) -> list[ColumnElement[bool]]:
    """WHERE clauses selecting the live records of `c` this space may read."""
    clauses = [Record.collection_id == c.id, Record.deleted_at.is_(None)]
    match c.scope:
        case CollectionScope.PERSONAL:
            clauses.append(Record.author_user_id == space.user_id)
        case CollectionScope.SHARED:
            if not space.is_owner:
                clauses.append(Record.author_user_id == space.user_id)
        case CollectionScope.GROUP:
            clauses.append(Record.tg_chat_id == space.tg_chat_id)
    return clauses


def can_change(space: DataSpace, c: Collection, r: Record) -> bool:
    """Whether the space may edit or delete `r`, a record it can already read."""
    if r.author_user_id == space.user_id:
        return True
    match c.scope:
        case CollectionScope.SHARED:
            return space.is_owner
        case CollectionScope.GROUP:
            return space.is_group_admin
    return False


def record_scope_key(c: Collection, r: Record) -> str:
    """Where a record's unique rules apply."""
    match c.scope:
        case CollectionScope.PERSONAL:
            return f"u:{r.author_user_id}"
        case CollectionScope.GROUP:
            return f"c:{r.tg_chat_id}"
    return "all"


def payer(space: DataSpace, c: Collection) -> tuple[int, str]:
    """Whose plan limits a collection's records: (user id, plan name)."""
    if c.scope == CollectionScope.PERSONAL:
        return space.user_id, space.plan
    return space.owner_id, space.owner_plan


def tz_for(space: DataSpace, c: Collection) -> ZoneInfo:
    if c.scope == CollectionScope.PERSONAL:
        return ZoneInfo(space.timezone)
    return ZoneInfo(space.owner_timezone)
```

```python
"""Collections and record writes. Every record access takes a DataSpace (obot.data.space);
do not query Collection, Record or RecordKey anywhere else."""

import re

from sqlalchemy import delete, exists, func, or_, select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.ext.asyncio import AsyncSession

from obot.billing.plans import Pricing
from obot.data.errors import CollectionNotFound, InvalidSchema, LimitReached, NotAllowed
from obot.data.schema import KEY_PATTERN, CollectionSchema, check_evolution
from obot.data.space import DataSpace, visible
from obot.db.models import Bot, Collection, CollectionScope, Record, RecordKey, User


def collection_schema(c: Collection) -> CollectionSchema:
    return CollectionSchema.model_validate({"fields": c.schema["fields"], "rules": c.rules})


def _store_schema(c: Collection, schema: CollectionSchema) -> None:
    dumped = schema.model_dump(mode="json")
    c.schema = {"fields": dumped["fields"]}
    c.rules = dumped["rules"]


async def create_collection(
    session: AsyncSession,
    pricing: Pricing,
    *,
    bot: Bot,
    key: str,
    title: dict[str, str],
    scope: CollectionScope,
    schema: CollectionSchema,
    created_by: User | None = None,
) -> Collection:
    """A template collection (created_by None, counted against the owner's plan), or a
    personal one a person made in chat (counted against theirs). Callers check that the
    caller is the owner for template collections."""
    if created_by is not None and scope != CollectionScope.PERSONAL:
        raise NotAllowed("only personal collections can be made in chat")
    if not re.fullmatch(KEY_PATTERN, key):
        raise InvalidSchema(f"{key!r} is not a valid collection key")
    plan_user = created_by or await session.get(User, bot.owner_id)
    count = await session.scalar(
        select(func.count(Collection.id)).where(
            Collection.bot_id == bot.id,
            Collection.created_by_user_id.is_(None)
            if created_by is None
            else Collection.created_by_user_id == created_by.id,
        )
    )
    if count >= pricing.plan(plan_user.plan).max_data_collections:
        raise LimitReached("collections")
    # A template key clashes with template keys; a personal key also with the template's,
    # so a person's own collection never shadows a template one.
    owners = [Collection.created_by_user_id.is_(None)]
    if created_by is not None:
        owners.append(Collection.created_by_user_id == created_by.id)
    taken = await session.scalar(
        select(
            exists().where(Collection.bot_id == bot.id, Collection.key == key, or_(*owners))
        )
    )
    if taken:
        raise InvalidSchema(f"a collection named {key!r} exists")
    c = Collection(
        bot_id=bot.id,
        key=key,
        title=title,
        scope=scope,
        created_by_user_id=created_by.id if created_by else None,
    )
    _store_schema(c, schema)
    try:
        async with session.begin_nested():
            session.add(c)
            await session.flush()
    except IntegrityError:
        raise InvalidSchema(f"a collection named {key!r} exists") from None
    return c


async def list_collections(session: AsyncSession, space: DataSpace) -> list[Collection]:
    rows = await session.scalars(
        select(Collection)
        .where(
            Collection.bot_id == space.bot_id,
            Collection.created_by_user_id.is_(None)
            | (Collection.created_by_user_id == space.user_id),
        )
        .order_by(Collection.id)
    )
    return [c for c in rows if visible(space, c)]


async def get_collection(session: AsyncSession, space: DataSpace, key: str) -> Collection:
    for c in await list_collections(session, space):
        if c.key == key:
            return c
    raise CollectionNotFound(key)


async def update_collection_schema(
    session: AsyncSession, c: Collection, new: CollectionSchema
) -> None:
    """Replace the schema; additive changes only once the collection has records.
    Callers check that the caller may edit the collection (owner, or its personal creator)."""
    has_records = await session.scalar(
        select(exists().where(Record.collection_id == c.id, Record.deleted_at.is_(None)))
    )
    check_evolution(collection_schema(c), new, has_records=has_records)
    _store_schema(c, new)
    c.schema_version += 1
    kept = [",".join(group) for group in new.rules.unique]
    await session.execute(
        delete(RecordKey).where(RecordKey.collection_id == c.id, RecordKey.rule.not_in(kept))
    )
    await session.flush()


async def delete_collection(session: AsyncSession, c: Collection) -> None:
    """Delete a collection with all its records."""
    await session.execute(delete(Collection).where(Collection.id == c.id))
    session.expunge(c)
```

```python
async def get_record(
    session: AsyncSession, space: DataSpace, c: Collection, record_id: int
) -> Record:
    record = await session.scalar(
        select(Record).where(Record.id == record_id, *row_filter(space, c))
    )
    if record is None:
        raise RecordNotFound(record_id)
    return record


def _check_size(pricing: Pricing, space: DataSpace, c: Collection, data: dict) -> None:
    size = len(json.dumps(data, ensure_ascii=False).encode())
    if size > pricing.plan(payer(space, c)[1]).max_record_bytes:
        raise LimitReached("record_bytes")


async def _check_record_count(
    session: AsyncSession, pricing: Pricing, space: DataSpace, c: Collection
) -> None:
    # Checked before the insert, so concurrent writers may overshoot by a record or two.
    user_id, plan = payer(space, c)
    query = (
        select(func.count(Record.id))
        .join(Collection, Collection.id == Record.collection_id)
        .where(Record.bot_id == c.bot_id, Record.deleted_at.is_(None))
    )
    if c.scope == CollectionScope.PERSONAL:
        query = query.where(
            Collection.scope == CollectionScope.PERSONAL, Record.author_user_id == user_id
        )
    else:
        query = query.where(Collection.scope != CollectionScope.PERSONAL)
    if await session.scalar(query) >= pricing.plan(plan).max_data_records:
        raise LimitReached("records")


async def _claim_keys(
    session: AsyncSession, c: Collection, record: Record, schema: CollectionSchema
) -> None:
    """Insert the record's unique keys; a key someone else holds is a duplicate. A concurrent
    holder that has not committed yet makes Postgres wait for it, so exactly one writer wins."""
    for rule, value_hash in unique_keys(schema, record.data):
        claimed = await session.scalar(
            insert(RecordKey)
            .values(
                collection_id=c.id,
                rule=rule,
                scope_key=record_scope_key(c, record),
                value_hash=value_hash,
                record_id=record.id,
            )
            .on_conflict_do_nothing()
            .returning(RecordKey.rule)
        )
        if claimed is None:
            raise DuplicateRecord(rule.split(","))


async def add_record(
    session: AsyncSession, pricing: Pricing, space: DataSpace, c: Collection, data: dict
) -> Record:
    schema = collection_schema(c)
    tz = tz_for(space, c)
    values = validate_record(schema, data, tz)
    check_allowed_hours(schema, values, tz)
    _check_size(pricing, space, c, values)
    await _check_record_count(session, pricing, space, c)
    record = Record(
        collection_id=c.id,
        bot_id=c.bot_id,
        author_user_id=space.user_id,
        tg_chat_id=space.tg_chat_id if c.scope == CollectionScope.GROUP else None,
        data=values,
        schema_version=c.schema_version,
    )
    async with session.begin_nested():
        session.add(record)
        await session.flush()
        await _claim_keys(session, c, record, schema)
    return record


async def _locked_record(
    session: AsyncSession, space: DataSpace, c: Collection, record_id: int
) -> Record:
    record = await session.scalar(
        select(Record).where(Record.id == record_id, *row_filter(space, c)).with_for_update()
    )
    if record is None:
        raise RecordNotFound(record_id)
    if not can_change(space, c, record):
        raise NotAllowed("only the author can change this record")
    return record


async def update_record(
    session: AsyncSession,
    pricing: Pricing,
    space: DataSpace,
    c: Collection,
    record_id: int,
    changes: dict,
    *,
    expected_version: int | None = None,
) -> Record:
    """Merge `changes` into the record. The row is locked, so concurrent updates never lose
    each other's fields; `expected_version` (from the panel) refuses edits of a stale copy."""
    record = await _locked_record(session, space, c, record_id)
    if expected_version is not None and record.version != expected_version:
        raise StaleRecord()
    schema = collection_schema(c)
    tz = tz_for(space, c)
    values = validate_record(schema, changes, tz, current=record.data)
    check_allowed_hours(schema, values, tz)
    _check_size(pricing, space, c, values)
    async with session.begin_nested():
        await session.execute(delete(RecordKey).where(RecordKey.record_id == record.id))
        record.data = values
        record.version += 1
        record.schema_version = c.schema_version
        await session.flush()
        await _claim_keys(session, c, record, schema)
    return record


async def delete_record(
    session: AsyncSession, space: DataSpace, c: Collection, record_id: int
) -> None:
    """Soft delete: the record disappears now and is purged later; its unique keys are freed."""
    record = await _locked_record(session, space, c, record_id)
    record.deleted_at = datetime.now(UTC)
    await session.execute(delete(RecordKey).where(RecordKey.record_id == record.id))
    await session.flush()


async def purge_deleted_records(session: AsyncSession, retention_days: int) -> int:
    cutoff = datetime.now(UTC) - timedelta(days=retention_days)
    result = await session.execute(delete(Record).where(Record.deleted_at < cutoff))
    return result.rowcount
```

```python
"""Reading records: structured filters, availability of shared slots and summaries.

Bots never write SQL: they pass Filter values, which are checked against the schema and
compiled here. Sums and counts run in the database, not in the model (SPEC 8.8).
"""

import enum
from collections.abc import Sequence
from dataclasses import dataclass
from decimal import Decimal
from typing import Any
from zoneinfo import ZoneInfo

from sqlalchemy import TIMESTAMP, ColumnElement, Date, Numeric, cast, func, select, text
from sqlalchemy.ext.asyncio import AsyncSession

from obot.data.errors import InvalidQuery
from obot.data.repository import collection_schema
from obot.data.schema import NUMERIC_TYPES, CollectionSchema, FieldDef, FieldType, normalize_value
from obot.data.space import DataSpace, row_filter, tz_for
from obot.db.models import Collection, CollectionScope, Record

MAX_FIND = 100
MAX_GROUPS = 100


class FilterOp(enum.StrEnum):
    EQ = "eq"
    NE = "ne"
    LT = "lt"
    LTE = "lte"
    GT = "gt"
    GTE = "gte"
    CONTAINS = "contains"
    IN = "in"


@dataclass(frozen=True)
class Filter:
    field: str
    op: FilterOp
    value: Any


class Metric(enum.StrEnum):
    COUNT = "count"
    SUM = "sum"
    AVG = "avg"
    MIN = "min"
    MAX = "max"


class Period(enum.StrEnum):
    DAY = "day"
    WEEK = "week"  # weeks start on Monday
    MONTH = "month"


@dataclass(frozen=True)
class SummaryRow:
    group: str | None
    value: Decimal


def _field(schema: CollectionSchema, key: str) -> FieldDef:
    f = schema.field(key)
    if f is None or f.hidden:
        raise InvalidQuery(f"unknown field {key!r}")
    return f


def _typed(f: FieldDef) -> ColumnElement:
    """The field's value as a comparable SQL expression."""
    if f.type in NUMERIC_TYPES:
        return cast(Record.data[f.key].astext, Numeric)
    if f.type == FieldType.BOOLEAN:
        return Record.data[f.key].as_boolean()
    # ISO dates, times and datetimes compare correctly as text.
    return Record.data[f.key].astext


def _value(f: FieldDef, value: Any, tz: ZoneInfo) -> Any:
    try:
        stored = normalize_value(f, value, tz, check_limits=False)
    except (ValueError, TypeError) as e:
        raise InvalidQuery(f"{f.key}: {e}") from None
    return Decimal(stored) if f.type in NUMERIC_TYPES else stored


def _escape_like(value: str) -> str:
    return value.replace("\\", "\\\\").replace("%", "\\%").replace("_", "\\_")


def _condition(schema: CollectionSchema, flt: Filter, tz: ZoneInfo) -> ColumnElement[bool]:
    f = _field(schema, flt.field)
    if flt.op == FilterOp.CONTAINS:
        if f.type not in (FieldType.TEXT, FieldType.PHONE):
            raise InvalidQuery(f"{f.key}: contains works on text fields only")
        needle = _escape_like(str(flt.value).strip())
        return Record.data[f.key].astext.ilike(f"%{needle}%", escape="\\")
    expr = _typed(f)
    if flt.op == FilterOp.IN:
        if not isinstance(flt.value, list | tuple) or not flt.value:
            raise InvalidQuery(f"{f.key}: 'in' needs a non-empty list")
        return expr.in_([_value(f, v, tz) for v in flt.value])
    value = _value(f, flt.value, tz)
    match flt.op:
        case FilterOp.EQ:
            return expr == value
        case FilterOp.NE:
            return expr != value
        case FilterOp.LT:
            return expr < value
        case FilterOp.LTE:
            return expr <= value
        case FilterOp.GT:
            return expr > value
        case FilterOp.GTE:
            return expr >= value
    raise InvalidQuery(f"unknown operator {flt.op!r}")


async def find_records(
    session: AsyncSession,
    space: DataSpace,
    c: Collection,
    filters: Sequence[Filter] = (),
    *,
    sort: str | None = None,
    descending: bool = True,
    limit: int = 20,
) -> list[Record]:
    """Records of `c` the space may read, newest first unless sorted by a field."""
    schema = collection_schema(c)
    tz = tz_for(space, c)
    query = select(Record).where(
        *row_filter(space, c), *[_condition(schema, f, tz) for f in filters]
    )
    if sort is not None:
        key = _typed(_field(schema, sort))
        query = query.order_by(
            key.desc().nulls_last() if descending else key.asc().nulls_last(), Record.id
        )
    else:
        query = query.order_by(Record.id.desc() if descending else Record.id)
    rows = await session.scalars(query.limit(max(1, min(limit, MAX_FIND))))
    return list(rows)


async def availability(
    session: AsyncSession,
    space: DataSpace,
    c: Collection,
    filters: Sequence[Filter] = (),
    *,
    limit: int = 50,
) -> list[dict[str, Any]]:
    """The public fields of matching records of a shared collection, whoever wrote them:
    enough to tell that a slot is taken, never by whom (SPEC 8.8)."""
    if c.scope != CollectionScope.SHARED:
        raise InvalidQuery("availability works on shared collections only")
    schema = collection_schema(c)
    public = [f.key for f in schema.fields if f.public and not f.hidden]
    if not public:
        raise InvalidQuery("this collection has no public fields")
    if any(f.field not in public for f in filters):
        raise InvalidQuery("availability can filter on public fields only")
    tz = tz_for(space, c)
    rows = await session.scalars(
        select(Record.data)
        .where(
            Record.collection_id == c.id,
            Record.deleted_at.is_(None),
            *[_condition(schema, f, tz) for f in filters],
        )
        .order_by(Record.id)
        .limit(max(1, min(limit, MAX_FIND)))
    )
    return [{k: data[k] for k in public if k in data} for data in rows]


def _period_expr(schema: CollectionSchema, period: Period, field: str | None, tz: ZoneInfo):
    if field is None:
        dated = [
            f for f in schema.fields
            if f.type in (FieldType.DATE, FieldType.DATETIME) and not f.hidden
        ]
        if not dated:
            raise InvalidQuery("grouping by period needs a date field")
        f = dated[0]
    else:
        f = _field(schema, field)
        if f.type not in (FieldType.DATE, FieldType.DATETIME):
            raise InvalidQuery(f"{f.key} is not a date field")
    if f.type == FieldType.DATE:
        day = cast(Record.data[f.key].astext, Date)
    else:
        moment = cast(Record.data[f.key].astext, TIMESTAMP(timezone=True))
        day = func.timezone(tz.key, moment)
    fmt = "YYYY-MM" if period == Period.MONTH else "YYYY-MM-DD"
    return func.to_char(func.date_trunc(period.value, day), fmt)


async def summarize(
    session: AsyncSession,
    space: DataSpace,
    c: Collection,
    metric: Metric,
    field: str | None = None,
    *,
    filters: Sequence[Filter] = (),
    group_by: str | None = None,
    period: Period | None = None,
    period_field: str | None = None,
) -> list[SummaryRow]:
    """count/sum/avg/min/max over the records the space may read, optionally grouped by a
    field or by day/week/month of a date field (the first one unless `period_field`)."""
    schema = collection_schema(c)
    tz = tz_for(space, c)
    if metric == Metric.COUNT:
        value = func.count(Record.id)
    else:
        if field is None:
            raise InvalidQuery(f"{metric} needs a field")
        f = _field(schema, field)
        if f.type not in NUMERIC_TYPES:
            raise InvalidQuery(f"{f.key} is not a number")
        value = getattr(func, metric.value)(_typed(f))
    if group_by is not None and period is not None:
        raise InvalidQuery("group by a field or by a period, not both")
    if group_by is not None:
        group = Record.data[_field(schema, group_by).key].astext
    elif period is not None:
        group = _period_expr(schema, period, period_field, tz)
    else:
        group = None

    where = [*row_filter(space, c), *[_condition(schema, f, tz) for f in filters]]
    if group is None:
        result = await session.scalar(select(value).where(*where))
        return [SummaryRow(None, Decimal(result or 0))]
    # Group and order by the output alias: repeating the expression would repeat its bind
    # parameters, which Postgres does not treat as the same expression.
    rows = await session.execute(
        select(group.label("g"), value.label("v"))
        .where(*where)
        .group_by(text("g"))
        .order_by(text("g"))
        .limit(MAX_GROUPS)
    )
    return [SummaryRow(g, Decimal(v or 0)) for g, v in rows]
```

```python
"""Background work on bots' structured data."""

import logging

from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

from obot.data.repository import purge_deleted_records

log = logging.getLogger(__name__)


async def purge_records(
    sessionmaker: async_sessionmaker[AsyncSession], retention_days: int
) -> None:
    async with sessionmaker() as session:
        purged = await purge_deleted_records(session, retention_days)
        await session.commit()
    if purged:
        log.info("purged %d data records deleted over %d days ago", purged, retention_days)
```
