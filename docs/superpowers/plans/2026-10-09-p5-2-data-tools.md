# P5-2: Data Tools in Chat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let bots read and write their collections from a private chat (and from tasks and ask_bot runs), so an expense book or a booking bot works end to end with the model calling `data_find`, `data_add`, `data_update`, `data_delete` and `data_summarize`.

**Architecture:** Three layers, matching the existing tools. `obot/data/format.py` turns collections, records, summaries and `DataError`s into text for the model (pure). `obot/data/service.py` (`DataService`) runs each tool call in its own DB session on behalf of one person in a private context and commits writes immediately, so no row locks or unique keys are held while the model thinks. `obot/core/tools.py` gets platform-independent tool functions that call a `DataTools` protocol on `ToolServices.data`. `obot/telegram/data_chat.py` adds the Telegram parts: a once-per-person notice that the owner sees shared records, and a confirm button for deletes. `obot/telegram/toolkit.py` wires it in; group chats get no data tools until P5-7.

**Tech Stack:** Python 3.13, pydantic-ai tools, SQLAlchemy 2 async, aiogram 3, Redis, pytest-asyncio.

**Spec:** `docs/SPEC.md` section ۸٫۸ (rows P5-2). Builds on the P5-1 data core in `backend/src/obot/data/` (branch `p5-data-core`).

## Global Constraints

- Records are read and written only through `obot.data` with a `DataSpace` (AGENTS.md). Telegram code never queries `Record` or `RecordKey`.
- The model never writes SQL: filters are `{field, op, value}` objects with `op` one of `eq, ne, lt, lte, gt, gte, contains, in`; metrics `count, sum, avg, min, max`; periods `day, week, month`.
- Tool failures return text starting with `ERROR:` (existing convention in `obot/core/tools.py`), never raise into the agent run.
- Data operations are free (no `UsageMeter` call); plan limits are enforced by `obot.data` itself.
- Deleting a record needs the person's confirmation with a button in their private chat with the bot; without a way to ask (no running client), `data_delete` returns an `ERROR:`.
- Before or with a person's first write to a shared collection they don't own, the bot tells them once (Redis-gated, deterministic, i18n fa/en) that the bot's owner sees what they enter there.
- In group chats the bot gets no data tools in P5-2 (group data is P5-7).
- `ask_bot` and chain steps work on the payer's data space of the bot that runs the step (SPEC ۸٫۸).
- All outgoing Telegram messages go through `runtime.sender` (AGENTS.md).
- Commit messages: one plain English imperative sentence, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never commit the user's untracked `backend/avatars.jsonl` or `backend/scripts/`.
- Dev infra must be up (`docker compose up -d` in the repo root). Run tests from `backend/`.

```python
"""Text the model reads about a bot's data: the collection catalog for its instructions,
records, summaries and errors (SPEC 8.8)."""

import json
from datetime import datetime
from decimal import Decimal
from typing import Any
from zoneinfo import ZoneInfo

from obot.data.errors import (
    CollectionNotFound,
    DataError,
    DuplicateRecord,
    LimitReached,
    OutsideAllowedHours,
    RecordInvalid,
    RecordNotFound,
)
from obot.data.query import Metric, SummaryRow
from obot.data.repository import collection_schema
from obot.data.schema import AllowedHours, FieldDef, FieldType
from obot.data.space import DataSpace
from obot.db.models import Collection, CollectionScope, Record

WEEKDAYS = ["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"]

DATA_RULES = (
    "Dates are Gregorian YYYY-MM-DD (convert Persian/Jalali dates first), times HH:MM "
    "(24h), datetimes YYYY-MM-DDTHH:MM in the user's local time. Save things the user asks "
    "you to keep with data_add, and never say something is saved unless data_add returned "
    "OK. Look records up with data_find and compute totals with data_summarize; never add "
    "numbers up yourself. Deleting shows the user a confirm button."
)


def _json(data: dict[str, Any]) -> str:
    return json.dumps(data, ensure_ascii=False)


def _number(value: Decimal) -> str:
    text = format(value, "f")
    if "." in text:
        text = text.rstrip("0").rstrip(".")
    return text or "0"


def describe_allowed(allowed: AllowedHours) -> str:
    return "; ".join(
        f"{','.join(WEEKDAYS[d] for d in w.weekdays)} {w.start:%H:%M}-{w.end:%H:%M}"
        for w in allowed.windows
    )


def _describe_field(f: FieldDef) -> str:
    kind = f"money {f.currency}" if f.type == FieldType.MONEY and f.currency else f.type.value
    if f.options:
        kind += ": " + "|".join(f.options)
    parts = [kind]
    if f.min is not None:
        parts.append(f"min {_number(f.min)}")
    if f.max is not None:
        parts.append(f"max {_number(f.max)}")
    if f.required:
        parts.append("required")
    labels = " / ".join(dict.fromkeys(f.label.values()))
    return f'{f.key} ({", ".join(parts)}) "{labels}"'


def _describe_scope(c: Collection, space: DataSpace) -> str:
    match c.scope:
        case CollectionScope.PERSONAL:
            return "personal: each user has their own records"
        case CollectionScope.SHARED if space.is_owner:
            return "shared: everyone who uses the bot adds records; this user owns this bot and sees everyone's records"
        case CollectionScope.SHARED:
            return (
                "shared: this user sees only this user's own records; to see what anyone has "
                "taken, call data_find with availability=true (public fields only)"
            )
    return "group: shared by the members of this group"


def describe_collections(collections: list[Collection], space: DataSpace, now: datetime) -> str:
    """The catalog that goes into the bot's instructions."""
    lines = ["Your data collections (use the data_* tools with these exact keys):"]
    for c in collections:
        schema = collection_schema(c)
        title = " / ".join(dict.fromkeys(c.title.values())) or c.key
        fields = "; ".join(_describe_field(f) for f in schema.fields if not f.hidden)
        line = f'- {c.key} "{title}" ({_describe_scope(c, space)}). Fields: {fields}.'
        for group in schema.rules.unique:
            line += f" Rule: at most one record per {'+'.join(group)}."
        if (allowed := schema.rules.allowed_hours) is not None:
            tz = space.timezone if c.scope == CollectionScope.PERSONAL else space.owner_timezone
            line += f" Allowed times ({tz}): {describe_allowed(allowed)}."
        public = [f.key for f in schema.fields if f.public and not f.hidden]
        if c.scope == CollectionScope.SHARED and public:
            line += f" public fields: {', '.join(public)}."
        lines.append(line)
    local = now.astimezone(ZoneInfo(space.timezone))
    lines.append(f"{DATA_RULES} Today is {local:%A %Y-%m-%d}, {local:%H:%M} in {space.timezone}.")
    return "\n".join(lines)


def format_records(records: list[Record], tz: ZoneInfo) -> str:
    if not records:
        return "No records."
    return "\n".join(
        f"#{r.id} ({r.created_at.astimezone(tz):%Y-%m-%d}) {_json(r.data)}" for r in records
    )


def format_taken(rows: list[dict[str, Any]]) -> str:
    if not rows:
        return "Nothing taken matches."
    return "\n".join(f"Taken: {_json(row)}" for row in rows)


def format_summary(rows: list[SummaryRow], metric: Metric) -> str:
    def value(v: Decimal) -> str:
        return _number(v.quantize(Decimal("0.01")) if metric == Metric.AVG else v)

    if len(rows) == 1 and rows[0].group is None:
        return f"{metric.value}: {value(rows[0].value)}"
    lines = [f"{metric.value} by group:"]
    lines += [f"{r.group if r.group is not None else '(empty)'}: {value(r.value)}" for r in rows]
    return "\n".join(lines)


def describe_error(e: DataError) -> str:
    match e:
        case RecordInvalid():
            text = "invalid values: " + "; ".join(f"{f.field}: {f.reason}" for f in e.errors)
        case DuplicateRecord():
            text = (
                f"a record with the same {', '.join(e.fields)} already exists (taken); "
                "suggest another"
            )
        case OutsideAllowedHours():
            text = f"outside the allowed times: {describe_allowed(e.allowed)}"
        case LimitReached() if e.limit == "records":
            text = "the record limit of the plan is reached"
        case LimitReached() if e.limit == "record_bytes":
            text = "the record is too large"
        case CollectionNotFound():
            text = f"there is no collection named {e.key!r}"
        case RecordNotFound():
            text = f"there is no record #{e.record_id} this user can see"
        case _:
            text = str(e)
    return f"ERROR: {text}."
```

"""The data_* tools' access to one bot's collections on behalf of one person, in a private
context: their chat with the bot, their task, or another bot's question for them.

Each call opens its own session and commits writes at once, so no row locks or unique keys
are held while the model is thinking, and a booking is saved even if the reply fails later.
"""

from collections.abc import Awaitable, Callable
from datetime import UTC, datetime
from typing import Any

from sqlalchemy.exc import DBAPIError
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker

NoticeShared = Callable[[], Awaitable[None]]
ConfirmDelete = Callable[[Collection, Record], Awaitable[str]]

# Postgres: deadlock detected, serialization failure.
RETRYABLE = {"40P01", "40001"}


def parse_filters(raw: list[dict[str, Any]] | None) -> list[Filter]:
    filters = []
    for item in raw or []:
        try:
            filters.append(Filter(str(item["field"]), FilterOp(item["op"]), item.get("value")))
        except (KeyError, TypeError, ValueError):
            ops = ", ".join(op.value for op in FilterOp)
            raise InvalidQuery(f"filters are {{field, op, value}} with op one of: {ops}") from None
    return filters


def _choice(enum_type, value: str | None, what: str):
    if value is None:
        return None
    try:
        return enum_type(value)
    except ValueError:
        options = ", ".join(m.value for m in enum_type)
        raise InvalidQuery(f"{what} must be one of: {options}") from None


def _sqlstate(e: DBAPIError) -> str | None:
    return getattr(e.orig, "sqlstate", None) or getattr(e.orig, "pgcode", None)


class DataService:
    def __init__(
        self,
        sessionmaker: async_sessionmaker[AsyncSession],
        pricing: Pricing,
        bot_id: int,
        user_id: int,
        *,
        notice_shared: NoticeShared | None = None,
        confirm_delete: ConfirmDelete | None = None,
    ) -> None:
        self._sessionmaker = sessionmaker
        self._pricing = pricing
        self._bot_id = bot_id
        self._user_id = user_id
        self._notice_shared = notice_shared
        self._confirm_delete = confirm_delete

    async def _space(self, session: AsyncSession) -> DataSpace:
        bot = await session.get(Bot, self._bot_id)
        user = await session.get(User, self._user_id)
        return await space_for(session, bot, user)

    async def note(self, session: AsyncSession) -> str | None:
        """The catalog for the bot's instructions; None when it has no collections here."""
        space = await self._space(session)
        collections = await list_collections(session, space)
        if not collections:
            return None
        return describe_collections(collections, space, datetime.now(UTC))

    async def _run(self, key: str, action, *, write: bool = False) -> str:
        try:
            async with self._sessionmaker() as session:
                space = await self._space(session)
                c = await get_collection(session, space, key.strip())
                text = await action(session, space, c)
                if write:
                    await session.commit()
                return text
        except DataError as e:
            return describe_error(e)
        except DBAPIError as e:
            if _sqlstate(e) in RETRYABLE:
                return "ERROR: someone changed this at the same moment; try again."
            raise

    async def find(
        self,
        collection: str,
        filters: list[dict[str, Any]] | None = None,
        sort: str | None = None,
        descending: bool = True,
        limit: int = 20,
        availability: bool = False,
    ) -> str:
        async def action(session, space, c):
            parsed = parse_filters(filters)
            if availability:
                return format_taken(await find_taken(session, space, c, parsed, limit=limit))
            records = await find_records(
                session, space, c, parsed, sort=sort, descending=descending, limit=limit
            )
            return format_records(records, tz_for(space, c))

        return await self._run(collection, action)

    async def add(self, collection: str, data: dict[str, Any]) -> str:
        async def action(session, space, c):
            record = await add_record(session, self._pricing, space, c, data)
            if (
                c.scope == CollectionScope.SHARED
                and not space.is_owner
                and self._notice_shared is not None
            ):
                await self._notice_shared()
            return f"OK: saved as #{record.id}: {json.dumps(record.data, ensure_ascii=False)}"

        return await self._run(collection, action, write=True)

    async def update(self, collection: str, record_id: int, changes: dict[str, Any]) -> str:
        async def action(session, space, c):
            record = await update_record(session, self._pricing, space, c, record_id, changes)
            return f"OK: #{record.id} is now {json.dumps(record.data, ensure_ascii=False)}"

        return await self._run(collection, action, write=True)

    async def delete(self, collection: str, record_id: int) -> str:
        if self._confirm_delete is None:
            return "ERROR: deleting needs the user's confirmation in their private chat."

        async def action(session, space, c):
            record = await get_record(session, space, c, record_id)
            if not can_change(space, c, record):
                raise NotAllowed("this user cannot delete this record")
            return await self._confirm_delete(c, record)

        return await self._run(collection, action)

    async def summarize(
        self,
        collection: str,
        metric: str,
        field: str | None = None,
        filters: list[dict[str, Any]] | None = None,
        group_by: str | None = None,
        period: str | None = None,
    ) -> str:
        async def action(session, space, c):
            chosen = _choice(Metric, metric, "metric")
            rows = await summarize(
                session,
                space,
                c,
                chosen,
                field,
                filters=parse_filters(filters),
                group_by=group_by,
                period=_choice(Period, period, "period"),
            )
            return format_summary(rows, chosen)

        return await self._run(collection, action)
```

def record_text(c: Collection, record: Record, lang: str) -> str:
    """The record as 'Label: value' lines in the person's language."""
    labels = {f.key: f.label.get(lang) or f.label.get("en") or f.key
              for f in collection_schema(c).fields}
    return "\n".join(f"{labels.get(k, k)}: {v}" for k, v in record.data.items())


class SharedNotice:
    """Tells a person once that the bot's owner sees what they save in shared collections."""

    def __init__(self, runtime: Runtime, bot: BotRecord, user: User) -> None:
        self._runtime = runtime
        self._bot_id, self._tg_bot_id = bot.id, bot.tg_bot_id
        self._user_id, self._tg_user_id = user.id, user.tg_user_id
        self._lang = lang_of(user.language)

    async def __call__(self) -> None:
        runtime = self._runtime
        key = f"data-shared-notice:{self._bot_id}:{self._user_id}"
        client = runtime.transport.client(self._tg_bot_id)
        if client is None or not await runtime.redis.set(key, 1, nx=True):
            return
        await runtime.sender.send_text(
            client, self._tg_user_id, t(self._lang, "data.shared_notice"), group=False
        )

    def __init__(self, runtime: Runtime, bot: BotRecord, user: User) -> None:
        self._runtime = runtime
        self._tg_bot_id = bot.tg_bot_id
        self._tg_user_id = user.tg_user_id
        self._lang = lang_of(user.language)

    async def __call__(self, c: Collection, record: Record) -> str:
        client = self._runtime.transport.client(self._tg_bot_id)
        if client is None:
            return "ERROR: cannot ask the user to confirm right now; try again later."
        lang = self._lang
        data = f"{c.id}:{record.id}"

@router.callback_query(F.data.startswith("data:"))
async def on_data_button(
    query: CallbackQuery, session: AsyncSession, bot_record: BotRecord, runtime: Runtime
) -> None:
    lang = lang_of(query.from_user.language_code)
    parts = query.data.split(":")
    if len(parts) != 4 or not (parts[2].isdigit() and parts[3].isdigit()):
        await query.answer()
        return
    _, action, collection_id, record_id = parts
    if action == "keep":
        await query.message.edit_text(t(lang, "data.kept"))
        await query.answer()
        return
    user = await started_user(session, bot_record, query.from_user.id)
    try:
        if user is None or not can_use(bot_record, query.from_user.id):
            raise DataError("not a user of this bot")
        space = await space_for(session, bot_record, user)
        c = await collection_by_id(session, space, int(collection_id))
        await delete_record(session, space, c, int(record_id))
    except DataError:
        await query.answer(t(lang, "data.not_yours"), show_alert=True)
        return
    await session.commit()
    await query.message.edit_text(t(lang, "data.deleted"))
    await query.answer()
```

`can_use` reads `bot_record.owner`; the managed-bot handlers get `bot_record` with the owner loaded (see `obot/telegram/scheduling.py`), and the test's `data_world.bot` came from `register_managed_bot`, which sets the relationship.
