# P5-6: Data in the Mini App Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In the Mini App, everyone who uses a bot opens "Data" and sees the collections they can reach, as a searchable, sortable table and, for collections with a date, a week calendar. They can add, edit and delete records with a form that fits each field type, and export a CSV that opens correctly in Excel. Owners, and the people who made a personal collection, can edit its schema additively, remove rules explicitly, and switch its notifications and reminders.

**Architecture:**
- **Backend:** a new router, `obot/api/data_routes.py`, serves `/api/bots/{bot_id}/collections/...`. Every call builds the caller's `DataSpace` and goes through `obot.data` (repository, query, events), so all access rules, limits, unique keys and events behave exactly as they do in chat. Data errors become structured HTTP errors (`{code, message, errors, fields}`), which the app translates.
- **CSV export:** it uses a short-lived signed link, so Telegram's `downloadFile` can fetch it without an auth header.
- **Frontend:** four new pages in the existing React app (`DataPage`, `CollectionPage`, `RecordForm`, `SchemaPage`). They are reached from the bot page, from "Bots I use", and from a `data_<bot>_<collection>` start param.

**Tech Stack:** FastAPI, SQLAlchemy 2 async, pydantic 2, pytest-asyncio + httpx (backend); React 19 + TypeScript + Vite, Telegram WebApp API (frontend).

**Spec:** `docs/SPEC.md` §8.8:
- "پنل: «ربات‌های من ← [ربات] ← داده‌ها»: جدول … فرم … تقویم … CSV با BOM. ویرایش افزایشی طرح فقط برای صاحب. لینک مستقیم … API در `/api/bots/{bot_id}/collections/...` از همان ریپازیتوری و `DataSpace` عبور می‌کند."
- P5-4/P5-5 rulings: removing a rule happens only explicitly in the panel, never by omission in the factory.

Builds on P5-1..P5-5 on branch `p5-data-core`.

## Global Constraints

- **Records only through obot.data:** every API route that touches records goes through `obot.data` with the caller's own `DataSpace`. Routes never query `Record` or `RecordKey` directly.
- **Panel scope = private chat scope:** the panel shows what the caller could reach in a private chat. That is personal collections (template ones and their own) and shared collections (all records for the owner, their own records for everyone else). Group collections are out of scope until P5-7.
- **Who may use the panel:** a bot must be ACTIVE and usable by the caller (`can_use`), or the routes answer 404. The routes never reveal that other people's bots, collections or records exist (404, not 403).
- **Who may edit a schema:**
  - **Allowed editors:** the bot's owner, for template collections; the person who made a personal collection, for their own.
  - **What edits are allowed:** additive only, enforced by `update_collection_schema` → `check_evolution`.
  - **Optimistic lock:** schema edits carry the collection's `schema_version` and answer 409 when it changed.
  - **Rules:** they are replaced as sent. This is the explicit way to remove a rule.
- **Record edits:** they carry the record's `version` and answer 409 when it changed (`StaleRecord`).
- **Error shape:** structured JSON `{"code": DataError.code or change code, "message": str, "errors": [{field, reason}], "fields": [...]}`. The app shows translated messages per code, with the field labels.
- **CSV:**
  - **Format:** UTF-8 with a BOM and visible fields only. Header labels are in the caller's language. Datetimes are shown in the collection's time zone.
  - **Download link:** signed with HMAC over the factory token, valid for 5 minutes, scoped to (bot, collection, user).
- **Plan limits:** they come from config, never hard-coded.
- **Commits:** one plain English imperative sentence, ending with a `Co-Authored-By:` trailer. Never commit the user's untracked `backend/avatars.jsonl` or `backend/scripts/`. Never run `ruff --fix` outside `src/` and `tests/`.
- **Checks:**
  - **Backend:** `cd backend && uv run pytest -q && uv run ruff check . && uv run ruff format --check .`
  - **Mini app:** `cd miniapp && npm run build && npm run lint`

```python
"""A bot's data in the panel (SPEC 8.8): the same collections, rules and events as in chat.

Every call builds the caller's DataSpace for the bot and goes through obot.data; errors come
back as {code, message, errors, fields} so the app can explain them in the user's language.
"""

import json
from datetime import datetime
from typing import Any

from fastapi import APIRouter, HTTPException, Query
from pydantic import BaseModel

from obot.api.deps import CurrentUser, Session, State, UsableBot
from obot.data.errors import (
    CollectionNotFound,
    DataError,
    DuplicateRecord,
    LimitReached,
    NotAllowed,
    RecordInvalid,
    RecordNotFound,
    SchemaChangeRejected,
    StaleRecord,
)
from obot.data.query import find_records
from obot.data.repository import (
    add_record,
    collection_by_id,
    collection_schema,
    delete_record,
    list_collections,
    update_record,
)
from obot.data.service import parse_filters
from obot.data.space import DataSpace, space_for, tz_for
from obot.db.models import Bot, Collection, Record, User

router = APIRouter(prefix="/api")

PAGE_MAX = 100


class CollectionOut(BaseModel):
    id: int
    key: str
    title: dict[str, str]
    scope: str
    mine: bool  # a personal collection this user made in chat
    can_edit: bool
    schema_version: int
    fields: list[dict[str, Any]]
    rules: dict[str, Any]
    events: dict[str, Any]
    timezone: str  # the time zone dates and times of this collection are in


class RecordOut(BaseModel):
    id: int
    data: dict[str, Any]
    version: int
    created_at: datetime
    mine: bool


class RecordsPage(BaseModel):
    records: list[RecordOut]
    has_more: bool


class RecordIn(BaseModel):
    data: dict[str, Any]


class RecordPatch(BaseModel):
    changes: dict[str, Any]
    version: int | None = None


def data_error(e: DataError) -> HTTPException:
    status = 422
    if isinstance(e, CollectionNotFound | RecordNotFound):
        status = 404
    elif isinstance(e, NotAllowed):
        status = 403
    elif isinstance(e, StaleRecord):
        status = 409
    elif isinstance(e, LimitReached):
        status = 403
    detail: dict[str, Any] = {"code": e.code, "message": str(e), "errors": [], "fields": []}
    if isinstance(e, RecordInvalid):
        detail["errors"] = [{"field": f.field, "reason": f.reason} for f in e.errors]
    if isinstance(e, DuplicateRecord):
        detail["fields"] = e.fields
    if isinstance(e, LimitReached):
        detail["limit"] = e.limit
    if isinstance(e, SchemaChangeRejected):
        detail["change"] = getattr(e, "change", None)
        detail["fields"] = [e.field] if getattr(e, "field", None) else []
    return HTTPException(status, detail)


def can_edit(c: Collection, bot: Bot, user: User) -> bool:
    if c.created_by_user_id is None:
        return bot.owner_id == user.id
    return c.created_by_user_id == user.id


def visible_data(c: Collection, data: dict[str, Any]) -> dict[str, Any]:
    hidden = {f.key for f in collection_schema(c).fields if f.hidden}
    return {k: v for k, v in data.items() if k not in hidden}


def record_out(c: Collection, r: Record, user: User) -> RecordOut:
    return RecordOut(
        id=r.id,
        data=visible_data(c, r.data),
        version=r.version,
        created_at=r.created_at,
        mine=r.author_user_id == user.id,
    )


def collection_out(c: Collection, bot: Bot, user: User, space: DataSpace) -> CollectionOut:
    return CollectionOut(
        id=c.id,
        key=c.key,
        title=c.title,
        scope=c.scope.value,
        mine=c.created_by_user_id == user.id,
        can_edit=can_edit(c, bot, user),
        schema_version=c.schema_version,
        fields=c.schema["fields"],
        rules=c.rules,
        events=c.events or {},
        timezone=tz_for(space, c).key,
    )


async def _space_and_collection(
    session, bot: Bot, user: User, collection_id: int
) -> tuple[DataSpace, Collection]:
    space = await space_for(session, bot, user)
    try:
        return space, await collection_by_id(session, space, collection_id)
    except DataError as e:
        raise data_error(e) from None


@router.get("/bots/{bot_id}/collections")
async def list_bot_collections(
    bot: UsableBot, user: CurrentUser, session: Session
) -> list[CollectionOut]:
    space = await space_for(session, bot, user)
    return [collection_out(c, bot, user, space) for c in await list_collections(session, space)]


@router.get("/bots/{bot_id}/collections/{collection_id}/records")
async def list_records(
    collection_id: int,
    bot: UsableBot,
    user: CurrentUser,
    session: Session,
    q: str | None = None,
    sort: str | None = None,
    desc: bool = True,
    filters: str | None = None,
    offset: int = Query(default=0, ge=0),
    limit: int = Query(default=50, ge=1, le=PAGE_MAX),
) -> RecordsPage:
    space, c = await _space_and_collection(session, bot, user, collection_id)
    try:
        raw = json.loads(filters) if filters else None
        parsed = parse_filters(raw)
        rows = await find_records(
            session, space, c, parsed, sort=sort, descending=desc, limit=limit + 1,
            search=q, offset=offset,
        )
    except json.JSONDecodeError:
        raise HTTPException(422, {"code": "invalid_query", "message": "bad filters"}) from None
    except DataError as e:
        raise data_error(e) from None
    return RecordsPage(
        records=[record_out(c, r, user) for r in rows[:limit]], has_more=len(rows) > limit
    )


@router.post("/bots/{bot_id}/collections/{collection_id}/records", status_code=201)
async def create_record(
    collection_id: int,
    body: RecordIn,
    bot: UsableBot,
    user: CurrentUser,
    session: Session,
    state: State,
) -> RecordOut:
    space, c = await _space_and_collection(session, bot, user, collection_id)
    try:
        record = await add_record(session, state.pricing, space, c, body.data)
    except DataError as e:
        raise data_error(e) from None
    await session.refresh(record)
    return record_out(c, record, user)


@router.patch("/bots/{bot_id}/collections/{collection_id}/records/{record_id}")
async def change_record(
    collection_id: int,
    record_id: int,
    body: RecordPatch,
    bot: UsableBot,
    user: CurrentUser,
    session: Session,
    state: State,
) -> RecordOut:
    space, c = await _space_and_collection(session, bot, user, collection_id)
    try:
        record = await update_record(
            session, state.pricing, space, c, record_id, body.changes,
            expected_version=body.version,
        )
    except DataError as e:
        raise data_error(e) from None
    await session.refresh(record)
    return record_out(c, record, user)


@router.delete(
    "/bots/{bot_id}/collections/{collection_id}/records/{record_id}", status_code=204
)
async def remove_record(
    collection_id: int, record_id: int, bot: UsableBot, user: CurrentUser, session: Session
) -> None:
    space, c = await _space_and_collection(session, bot, user, collection_id)
    try:
        await delete_record(session, space, c, record_id)
    except DataError as e:
        raise data_error(e) from None
```

```python
"""CSV export of a collection, fetched with a short-lived signed link so Telegram's
downloadFile can get it without our auth header (SPEC 8.8)."""

import base64
import csv
import hashlib
import hmac
import io
from datetime import datetime
from zoneinfo import ZoneInfo

from sqlalchemy.ext.asyncio import AsyncSession

from obot.data.describe import label_of
from obot.data.query import MAX_FIND, find_records
from obot.data.repository import collection_schema
from obot.data.schema import FieldType
from obot.data.space import DataSpace, tz_for
from obot.db.models import Collection

EXPORT_TTL = 300  # seconds


def _sign(secret: str, payload: str) -> str:
    key = hashlib.sha256(f"obot-export:{secret}".encode()).digest()
    mac = hmac.new(key, payload.encode(), hashlib.sha256).digest()
    return base64.urlsafe_b64encode(mac).decode().rstrip("=")


def make_token(secret: str, bot_id: int, collection_id: int, user_id: int, now: datetime) -> str:
    payload = f"{bot_id}.{collection_id}.{user_id}.{int(now.timestamp()) + EXPORT_TTL}"
    return f"{payload}.{_sign(secret, payload)}"


def read_token(secret: str, token: str, now: datetime) -> tuple[int, int, int] | None:
    """(bot_id, collection_id, user_id) of a valid, unexpired token; None otherwise."""
    payload, _, sig = token.rpartition(".")
    if not payload or not hmac.compare_digest(sig, _sign(secret, payload)):
        return None
    try:
        bot_id, collection_id, user_id, expires = (int(x) for x in payload.split("."))
    except ValueError:
        return None
    if now.timestamp() > expires:
        return None
    return bot_id, collection_id, user_id


def _cell(field_type: FieldType, value, tz: ZoneInfo) -> str:
    if value is None:
        return ""
    if field_type == FieldType.DATETIME and isinstance(value, str):
        try:
            moment = datetime.fromisoformat(value.replace("Z", "+00:00"))
            return moment.astimezone(tz).strftime("%Y-%m-%d %H:%M")
        except ValueError:
            return value
    if isinstance(value, bool):
        return "1" if value else "0"
    return str(value)


async def build_csv(session: AsyncSession, space: DataSpace, c: Collection, lang: str) -> str:
    """The records this space can read, visible fields only, with a BOM for Excel."""
    fields = [f for f in collection_schema(c).fields if not f.hidden]
    tz = tz_for(space, c)
    out = io.StringIO()
    out.write("﻿")
    writer = csv.writer(out)
    writer.writerow([label_of(f.label, lang, f.key) for f in fields])
    offset = 0
    while True:
        rows = await find_records(
            session, space, c, descending=False, limit=MAX_FIND, offset=offset
        )
        for r in rows:
            writer.writerow([_cell(f.type, r.data.get(f.key), tz) for f in fields])
        if len(rows) < MAX_FIND:
            break
        offset += MAX_FIND
    return out.getvalue()
```

The record limit (`max_data_records`) caps how many pages this can read.

class SchemaIn(BaseModel):
    fields: list[dict[str, Any]]
    rules: dict[str, Any] = {}
    title: dict[str, str] | None = None
    version: int


async def _editable(session, bot: Bot, user: User, collection_id: int):
    space = await space_for(session, bot, user)
    try:
        c = await lock_collection(session, space, collection_id)
    except DataError as e:
        raise data_error(e) from None
    if not can_edit(c, bot, user):
        raise HTTPException(404, {"code": "collection_not_found", "message": "not found"})
    return space, c


@router.put("/bots/{bot_id}/collections/{collection_id}/schema")
async def put_schema(
    collection_id: int, body: SchemaIn, bot: UsableBot, user: CurrentUser, session: Session
) -> CollectionOut:
    """Replace fields and rules (additive once there are records); rules are replaced as
    sent, which is how a rule is removed on purpose."""
    space, c = await _editable(session, bot, user, collection_id)
    if c.schema_version != body.version:
        raise HTTPException(409, {"code": "stale", "message": "the list changed meanwhile"})
    try:
        try:
            schema = CollectionSchema.model_validate({"fields": body.fields, "rules": body.rules})
        except ValidationError as e:
            raise InvalidSchema("; ".join(err["msg"] for err in e.errors())) from None
        await update_collection_schema(session, c, schema)
    except DataError as e:
        raise data_error(e) from None
    if body.title:
        c.title = {**c.title, **{k: v.strip() for k, v in body.title.items() if v.strip()}}
        await session.flush()
    return collection_out(c, bot, user, space)


@router.put("/bots/{bot_id}/collections/{collection_id}/events")
async def put_events(
    collection_id: int,
    body: CollectionEvents,
    bot: UsableBot,
    user: CurrentUser,
    session: Session,
) -> CollectionOut:
    space, c = await _editable(session, bot, user, collection_id)
    try:
        await set_collection_events(session, c, body)
    except DataError as e:
        raise data_error(e) from None
    return collection_out(c, bot, user, space)


class ExportOut(BaseModel):
    url: str
    file_name: str


@router.post("/bots/{bot_id}/collections/{collection_id}/export")
async def export_link(
    collection_id: int, bot: UsableBot, user: CurrentUser, session: Session, state: State
) -> ExportOut:
    _, c = await _space_and_collection(session, bot, user, collection_id)
    token = make_token(state.factory_token, bot.id, c.id, user.id, datetime.now(UTC))
    return ExportOut(url=f"/api/exports/{token}", file_name=f"{c.key}.csv")


@router.get("/exports/{token}")
async def export_csv(token: str, session: Session, state: State) -> Response:
    found = read_token(state.factory_token, token, datetime.now(UTC))
    if found is None:
        raise HTTPException(404, "link expired")
    bot_id, collection_id, user_id = found
    bot = await session.get(Bot, bot_id, options=[joinedload(Bot.owner)])
    user = await session.get(User, user_id)
    if (
        bot is None
        or user is None
        or user.is_disabled
        or bot.status != BotStatus.ACTIVE
        or not can_use(bot, user.tg_user_id)
    ):
        raise HTTPException(404, "link expired")
    space, c = await _space_and_collection(session, bot, user, collection_id)
    text = await build_csv(session, space, c, lang_of(user.language))
    return Response(
        content=text.encode("utf-8"),
        media_type="text/csv; charset=utf-8",
        headers={"Content-Disposition": f'attachment; filename="{c.key}.csv"'},
    )
